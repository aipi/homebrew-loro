# homebrew-loro

Homebrew tap for [Loro](https://github.com/aipi/loro) — local live speech-to-text
and a per-domain knowledge base (macOS, Apple Silicon).

```bash
brew tap aipi/loro
brew install --cask loro
```

Installs `Loro.app` plus its engine dependencies (`whisper-cpp`, `ffmpeg`).
Transcription models are downloaded on first use, verified by SHA-256.

> `Casks/loro.rb` is generated by the release workflow in `aipi/loro`
> (ADR-0006). Do not edit it by hand — it is overwritten on every release.
